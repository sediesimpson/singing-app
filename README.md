# Singing Trainer

A web app that helps beginners learn to sing. Sing into your mic and see your pitch live, then practise with guided exercises that score how closely you match each note.

## Features

- **Live pitch detection** in the browser. Your audio never leaves your device.
- **A scrolling pitch graph** that shows your voice against a target note.
- **Match the note:** hear a note, sing it back, and get a score with sharp/flat feedback.
- **Coming soon:** a 5-note scale exercise, accounts, progress tracking, a vocal range finder and a daily practice plan.

## Tech stack

Next.js · React · TypeScript · Tailwind · Web Audio API · [pitchy](https://github.com/ianprime0509/pitchy) · [smplr](https://github.com/danigb/smplr) · Supabase (planned)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and allow microphone access. Headphones are recommended.
